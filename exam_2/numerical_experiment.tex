\section{Numerical experiment}
\subsection{LMS experimentation}
Looking at the equations for the LMS filter, we're given some handles to tune the filter with
namely $\mu$, $M$ the amount of filter taps and $N$ how long the algorithm will run.

For the initial tests, we'll keep the amount of filter tabs fixed to $M=3$, and we'll instead 
vary the step size by a factor of 1000, and keep the test running for a 2000 samples. This is an
estimate to have enought samples to atleast at higher values for $\mu$ that the filter will converge.

The next experiment is increasing the filter taps, where $M = [3,5,10]$. This is done to observe
if increasing the filter tabs, beyond the amount of poles present in the unidentified system, has 
any influence on either convergence speed and accuracy.

\subsection{variable step-size experimentation}
The experiment with the variable step-size implementation, will be conducted 
in a slightly similar manner, however, in the regular LMS, we are \textit{almost} free to 
choose our values of $\mu$, however in the case for the variable step-size, some bounds are
defined, as qouted: \textit{"The minimum bound, which may be imposed on the variable
step-size parameters $\mu_i(n)'s$, can be as low as zero. However in actual practice, a positive bound is usually used"}.\cite[P179]{ASPbook}
Therefore stability is ensured if $trace(\mathbf{\mu}[n]\mathbf{R}) < \frac{1}{3}$. (equation 6.141)\cite[P179]{ASPbook} Which is the linear sum 
of the diagonal of the autocorrelation matrix and $\mu$ vector:
\[\mu_0[k] R_{00} + \mu_1[k] R_{11} + \dots + \mu_{M-1}[k] R_{M-1, M-1} < \frac{1}{3}\]
For white noise the autocorrelation matrix is: 
\[\mathbf{R} = \sigma^2_x \mathbf{I}\]
Because the unidentified system actually is 3 terms, $M=3$
This creates the constrains:
\[\mu_i \le \mu_{max}\]
Where the largest sum of values becomes:
\[\sum_{i=0}^{M-1} \le M\mu_{max}\]
This can rearranged:
\[\mu_{max} < \frac{1}{3M\sigma^2_x}\]
Since we already established the variance for the noise:
\[\mu_{max} < \frac{1}{3M}\]
And as already mentioned, in this case $M=3$, leads To
\[\mu_{max} = \frac{1}{3\cdot3} = \frac{1}{9} \approx 0.1111\]
\\
Instead changes to $\rho$ can be applied, thus our test cases will be varying values of this factor in small increments
of 0.0001, 0.001 and 0.005.

\subsection{LMS vs variable step-size LMS in system changes}
As another experiment, it will be shown how to two algorithms handle a sudden system change.
Here the unidentified system will change from $d[k] = 0.5x[k] + 0.25[k-1] - 0.3[k-2]$
to $d[k] = 0.8x[k] - 0.1[k-1] - 0.5[k-2]$. The point here is to see how fast the weights change 
and in case of the variable step-size, how the steps adapt to the sudden change.
The signal will remain the same, however after 2000 samples, it will suddenly change to the new
system and last for another 2000 samples. The tests are conducted with the same changes in $\mu$ 
and $\rho$ as mentioned in the other two tests.
